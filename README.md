<details>
<summary><b>🔍 More about how AURAGIX works (click to expand)</b></summary>

<br>

AURAGIX processes user-submitted text through the following stages:

<pre>
User submits text through Flask dashboard
                |
                v
Text preprocessing
(URLs, leetspeak, punctuation)
                |
                v
Groq API - Llama 3.3 70B
                |
                v
Classification and severity assessment
                |
                v
Rule-based severity scoring
                |
                v
BAN / WARNING / FLAG / ALLOW
                |
                v
CSV logging and dashboard update
</pre>

The numerical severity scores are application rules, not calibrated model probabilities.

AURAGIX was developed as an academic group project and is not hosted on this account.

</details>
