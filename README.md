### Selected Projects

**AURAGIX — AI-Based Content Moderation**

An academic group project that detects harmful text using a Flask backend and the Groq API (Llama 3.3 70B).

- Text preprocessing to handle URLs, leetspeak, and repeated punctuation
- Few-shot prompting for classification and severity assessment
- Rule-based moderation decisions and CSV logging
- Web dashboard for reviewing results

*Academic group project — not hosted on this GitHub profile.*

**[MyShell — Custom Command Line Shell](https://github.com/FilzaTanweer/myshell)**

A Unix-like command-line shell developed in C for an Operating Systems course.

- Command parsing and execution using fork(), execvp(), and waitpid()
- Input/output redirection and background process execution
- Signal handling, built-in commands, and command history
- Automated testing

**[Antique Car Rental System](https://github.com/FilzaTanweer/Antique-Car-Rental-System)**

A menu-driven rental management program written in MASM x86 Assembly.

- Customer booking and package-based billing
- Car search and popularity ranking
- Vendor earnings and administrative profit calculations
- Structured data handling using arrays and records
